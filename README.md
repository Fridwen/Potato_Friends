# 🏠 Roomio & Viewliet

> 사진과 조건만으로 더 구체적으로 살펴보는 대학가 자취방 탐색 서비스

Roomio는 예산, 위치, 면적, 옵션과 예상 생활비를 기준으로 매물을 탐색하고 비교하는 서비스입니다. Viewliet은 평면도와 실내 사진을 분석해 추정 공간 데이터를 만들고, Roomio에서 확인할 수 있는 2D 평면도와 3D 공간 모델을 제공합니다.

고려대학교 정보대학 2026 NewbieThon 21팀 프로젝트입니다.

---

## 문제 정의

기존 부동산 매물은 사진만 제공되는 경우가 많아 사진 사이의 연결 관계나 실제 공간감을 파악하기 어렵습니다. 월세와 관리비 외에 수도, 전기, 난방, 인터넷, 통학 교통비처럼 실제 생활에서 발생하는 비용도 한눈에 비교하기 어렵습니다.

Roomio & Viewliet은 다음 흐름으로 이 문제를 해결합니다.

```text
조건에 맞는 매물 검색
  → 지도에서 위치 확인
  → 실거주비용 계산
  → 관심 매물 비교
  → 3D 공간 확인
```

---

## 서비스 구성

### Roomio

대학생이 자신의 조건에 맞는 자취방을 찾고 비교하는 서비스입니다.

- 월세·전세 선택
- 보증금, 월세, 관리비, 면적, 학교까지 도보 시간 설정
- 풀옵션과 개별 옵션 검색
- 가격, 거리, 넓이 중요도를 반영한 추천
- 지도와 매물 카드가 연동되는 탐색 화면
- 최대 3개 매물 비교
- 매물별 관리비 포함 항목을 반영한 실거주비용 계산
- 저장된 JSON을 이용한 3D 공간 보기

### Viewliet

평면도와 실내 사진을 바탕으로 구조화된 공간 JSON을 생성하는 별도 Next.js 서비스입니다.

- 평면도 최대 1장 선택 업로드
- 실내 사진 1~6장 업로드
- 평면도만으로도 구조 분석 가능
- 전용면적을 반영한 공간 데이터 생성
- 동일 데이터를 사용하는 SVG 평면도와 Three.js 3D 모델
- 전체 공간 및 실내 시점 보기
- 앞쪽 벽 숨기기, 시점 회전, 전체 화면
- 결과 JSON 다운로드
- 업로드 파일 형식·크기와 AI 응답 스키마 검증

Viewliet이 생성한 JSON을 Roomio의 매물 데이터에 연결하면, 사용자가 검색 중 해당 매물의 3D 공간을 즉시 확인할 수 있습니다.

## 주요 기능

### 🎯 맞춤형 매물 추천

사용자가 입력한 조건으로 매물을 선별하고 가격, 학교와의 거리, 면적 가중치를 반영해 추천 순서를 계산합니다. 추천 결과에는 점수와 함께 주요 추천 이유가 표시됩니다.

풀옵션은 다음 핵심 항목을 모두 갖춘 경우로 정의합니다.

- 에어컨
- 냉장고
- 세탁기
- 조리시설(인덕션 또는 가스레인지)
- 침대
- 책상
- 옷장

### 🗺️ 지도 기반 매물 탐색

지도 마커와 하단 매물 카드가 서로 연동됩니다. 마커를 선택하면 해당 카드가 표시되고, 카드를 넘기면 지도도 매물 위치로 이동합니다.

### 💰 실거주비용 계산

월세와 관리비 외에 전기, 가스, 난방, 온수, 수도, 인터넷 및 선택적 교통비를 더해 월 예상 비용을 계산합니다. 관리비에 포함된 항목은 추가 비용을 0원으로 처리하며, 거주 개월 수에 따른 예상 총비용도 제공합니다.

> 공과금 사용량과 단가는 비교를 위한 예시값입니다. 공식 평균이나 실제 청구액을 보장하지 않습니다.

### ⚖️ 최대 3개 매물 비교

보증금, 월세, 관리비, 월세와 관리비 합계, 면적, 거리, 구조, 방향, 주차, 옵션과 예상 생활비 등을 한 표에서 비교합니다. 상대적으로 유리한 값을 색상으로 구분합니다.

### 🧊 3D 공간 보기

Viewliet에서 내려받은 JSON을 Roomio에 저장해 매물 상세 화면에서 바로 렌더링합니다. 현재 일부 매물만 3D 모델을 제공합니다.

## 데이터 및 3D 연동

매물 사진은 `frontend/public/properties/`에 저장하고 매물 객체의 `images` 배열에서 연결합니다.

```python
"images": [
    "/properties/room-1-1.jpg",
    "/properties/room-1-2.jpg"
]
```

Viewliet에서 생성한 공간 JSON은 `frontend/src/space/data/`에 저장하며, Roomio의 매물 ID와 연결합니다. 사용자가 매물을 열 때마다 AI를 다시 호출하지 않고 저장된 JSON을 렌더링하므로 조회 과정에서는 추가 API 비용이 발생하지 않습니다.

## 현재 구현 범위와 한계

- 현재 매물은 해커톤 시연을 위한 예시 데이터이며 실제 중개 서비스 데이터가 아닙니다.
- 학교와 도보 시간, 지도 좌표 중 일부는 추정값이므로 실제 경로와 다를 수 있습니다.
- Viewliet 결과는 사진과 선택적 평면도에서 추정한 모델이며 실측 도면, LiDAR 또는 사진측량 결과가 아닙니다.
- 사진에 보이지 않는 구조와 가구는 생성하지 않도록 제한하지만, 위치·크기·방향에는 오차가 발생할 수 있습니다.
- 현재 Roomio의 모든 매물에 3D JSON이 연결된 것은 아닙니다.
- 실거주비용은 예시 사용량과 단가를 이용한 비교용 추정치입니다.
- AI 호출 비용과 처리 시간은 모델, 이미지 수, 토큰 사용량과 환율에 따라 달라집니다.
- 실제 출시 시에는 공인중개사 또는 권리자로부터 매물 정보와 사진 이용 권한을 확보해야 합니다.
